# Архитектура GoGet

Десктопное приложение доставки с тремя ролями: **клиент**, **курьер**, **модератор**.

## Слои

```text
main.py                    # точка входа (Tkinter)
app/
  ui/                      # окна и виджеты
  auth/                    # регистрация / вход / bcrypt
  services/                # маршрутизация, геокод, корзина
  db/                      # SQL-запросы к MySQL
  config/                  # настройки из .env
assets/                    # иконки и изображения товаров
docker/mysql/init/         # схема + демо-seed
scripts/                   # служебные скрипты БД
tests/                     # pytest
```

## Потоки

1. **Клиент** выбирает категорию → товары → корзина → оформляет заказ.
2. **Модератор** видит новые заказы → назначает курьера (макс. 2 активных) → строится маршрут.
3. **Курьер** меняет статус и смотрит карту (folium + точки `ТочкиМаршрута`).

## Маршрутизация

`app/services/routing.py`:

1. Собирает точки «забрать» (магазины) и «доставить» (клиент).
2. Упорядочивает заборы: **Nearest Neighbor + 2-opt** (Haversine).
3. Доставка всегда последняя.
4. Пишет `Маршрут` и `ТочкиМаршрута`.

Геокод: `app/services/geocode.py` (парсинг координат или Nominatim OSM).

## Безопасность

- Пароли в БД - **bcrypt** (`app/auth/passwords.py`).
- Секреты БД - в `.env` (в git не коммитится); шаблон - `.env.example` / `.env.docker`.
- Ошибки пользователю - короткие; детали - в `logs/app.log`.

## База данных

MySQL 8 в Docker (`docker-compose.yml`, порт **3307**).  
Init-скрипты применяются только при первом создании volume.
